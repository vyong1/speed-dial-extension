# Description
<p>
This is a Chrome extension that replaces the new tab page with a speed dial page.
Each speed dial is a link with the logo of the website. 
</p>

# Requirements - Speed Dials
REQ_SPEEDDIALS_1. This extension shall replace the new tab page with a collection of speed dials
REQ_SPEEDDIALS_2. A speed dial shall link to a webpage
REQ_SPEEDDIALS_3. A speed dial shall be a clickable icon representing the webpage
REQ_SPEEDDIALS_4. A speed dial's icon shall be the webpage's favicon.ico by default
REQ_SPEEDDIALS_5. Users shall be able to add speed dials
REQ_SPEEDDIALS_6. Users shall be able to delete speed dials
REQ_SPEEDDIALS_7. Added speed dials shall be persist between chrome restarts

# Requirements (UI)
REQ_UI_1. The user shall be required to confirm for deleting speed dials
REQ_UI_2. The page shall have a light theme
REQ_UI_3. The page shall have a dark theme
REQ_UI_4. Users shall be able to toggle between themes
REQ_UI_5. Users shall be able to edit the name of a speed dial
REQ_UI_6. Users shall be able to import and export all the speed dials
