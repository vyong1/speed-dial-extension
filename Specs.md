# Description
<p>
This is a Chrome extension that replaces the new tab page with a speed dial page.
Each speed dial is a link with the logo of the website. 
</p>

# Requirements
1. This extension shall replace the new tab page with a collection of speed dials
2. A speed dial shall link to a webpage
3. A speed dial shall be a clickable icon representing the webpage
4. A speed dial's icon shall be the webpage's favicon.ico by default
5. Users shall be able to add speed dials
6. Users shall be able to delete speed dials
7. Added speed dials shall be persist between chrome restarts
8. The page shall have a light theme
9. The page shall have a dark theme
10. Users shall be able to toggle between themes
11. Users shall be able to edit the name of a speed dial
12. Users shall be able to import and export all the speed dials
